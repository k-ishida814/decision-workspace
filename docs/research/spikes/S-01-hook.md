## 構成

| ファイル      | 役割                                                                                                        |
| ------------- | ----------------------------------------------------------------------------------------------------------- |
| `hook.ts`     | Hook 本体。質問を `.spool/pending/` に書き、`.spool/answers/` を待つ。全イベントを `.spool/hook.log` に記録 |
| `answer.ts`   | 別ターミナルで動かす回答 CLI（TUI の代役）                                                                  |
| `playground/` | Hook 設定済みの検証用プロジェクト（`.claude/settings.json`）                                                |

## 手順

ターミナルを2つ使う。

```sh
# ターミナル A: 回答 CLI
bun spikes/s01-hook/answer.ts

# ターミナル B: 検証用プロジェクトで Claude Code を起動
cd spikes/s01-hook/playground
claude
```

初回起動時、プロジェクトの Hook を信頼するか確認されたら許可する。`/hooks` で `PreToolUse` に `AskUserQuestion` の Hook があることを確認できる。

Claude には、たとえば次のように頼むと `AskUserQuestion` を使わせやすい。

> AskUserQuestion ツールを使って、好きなプログラミング言語を（選択肢3つで）聞いてください。

回答 CLI の入力方法:

- `1` / `1,3`（複数選択） … 選択肢を選ぶ
- 任意の文字列 … 自由入力として送る
- `t` … フォールバック（その呼び出しは Claude Code の通常 UI で答える）

### 結果（2026-11-13）

| #   | 結果    | メモ                                                                                                                                                                                                                                                                                        |
| --- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | ✅      | 回答が Claude に届いた。待機中は初版ではスピナーだけだったが、`statusMessage` を設定すると `✽ Philosophizing… (Decision Workspace で回答待ち（TUI を確認してください）… 1/2 · 20s)` のように表示された。`1/2` は同じイベントで動く Hook の数（ユーザー側の別 Hook と合わせて2つ）と思われる |
| 2   | ✅      | 複数選択は `"VS Code, JetBrains"`（`, ` 区切り）で届いた                                                                                                                                                                                                                                    |
| 3   | ✅      | 3問の回答が1回でまとめて届いた                                                                                                                                                                                                                                                              |
| 4   | ✅      | 選択肢にない自由入力（`寿司`）も受理された                                                                                                                                                                                                                                                  |
| 5   | ✅      | フォールバックで通常 UI に渡せた                                                                                                                                                                                                                                                            |
| 6   | ⚠️→修正 | `Esc` で Claude Code は Hook に **SIGTERM** を送る（ログで確認）。ただし初版の Hook は `pending/` を消さずに終了したため、answer.ts に質問が残り続けた。終了・タイムアウト時に質問を取り下げるよう修正し、answer.ts / S-02 TUI でもキャンセルを表示するようにした。**要再確認**             |
| 7   | ✅      | 待機中も Claude Code 側で普通に文字を打てる（操作はブロックされない）                                                                                                                                                                                                                       |
| 8a  | ✅      | Hook 側が20秒で諦める → 質問を取り下げ → Claude Code に通常の質問 UI が出た                                                                                                                                                                                                                 |
| 8b  | ✅      | Claude Code 側が15秒で Hook に SIGTERM → 質問を取り下げ → 通常の質問 UI が出た（8a と同じ見え方）                                                                                                                                                                                           |

結論: **Hook でユーザーの回答を待つ方式は実用になる。** 回答・フォールバック・キャンセル・時間切れのどの経路でも Claude Code を止めず、時間切れのときは Claude Code の通常 UI が自然な受け皿になる。

その他の発見:

- Hook の入力には `session_id` / `tool_use_id` / `transcript_path` / `cwd` / `permission_mode` のほか、`prompt_id` / `effort` / `scratchpad_dir` が含まれる。
- `tool_use_id` は呼び出しごとに一意で、Decision のバッチ ID として使える。

### 入力例

Claude が `AskUserQuestion` を使わずに文章で聞き返すことがあるので、どの例でもツール名を明示する。

| #   | Claude Code への入力                                                                                                                                                                                      | answer.ts での操作                          |
| --- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- |
| 1   | `AskUserQuestion ツールで「好きなプログラミング言語は？」を、TypeScript / Rust / Go の3択（単一選択）で1問だけ聞いて。回答を受け取ったら、受け取った内容をそのまま教えて。`                               | `2`                                         |
| 2   | `AskUserQuestion ツールで「使ったことのあるエディタは？」を、VS Code / Neovim / JetBrains / Zed の4択・multiSelect: true で聞いて。受け取った回答を原文のまま表示して。`                                  | `1,3`                                       |
| 3   | `AskUserQuestion ツールを1回だけ呼んで、次の3問を同時に聞いて。(1) 好きな季節（春/夏/秋/冬） (2) 朝型か夜型か（朝型/夜型） (3) 好きな飲み物（コーヒー/紅茶/水）。受け取った3つの回答をそれぞれ表示して。` | `1` → `2` → `3`                             |
| 4   | `AskUserQuestion ツールで「今日のランチは？」を、ラーメン / カレー / そば の3択で聞いて。受け取った回答を原文のまま表示して。`                                                                            | `寿司`                                      |
| 5   | #1 と同じ                                                                                                                                                                                                 | `t`                                         |
| 6   | #1 と同じ                                                                                                                                                                                                 | 何もせず、Claude Code で `Esc`              |
| 7   | #1 と同じ                                                                                                                                                                                                 | 何もせず、Claude Code で文字を打つ          |
| 8a  | `SPIKE_WAIT_SEC=20 claude` で起動し #1 と同じ                                                                                                                                                             | 何もせず20秒待つ                            |
| 8b  | `playground/.claude/settings.json` の `timeout` を `15` にして再起動し #1 と同じ                                                                                                                          | 何もせず15秒待つ（終わったら `600` に戻す） |

#6〜#8 の後に古い質問が残って次の質問が出ない場合は、answer.ts を止めて `.spool` を消してから起動し直す。

ログは `spikes/s01-hook/.spool/hook.log` に出る（`input` イベントに Claude Code から届いた生データが入る）。
